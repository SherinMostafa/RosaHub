# Rosahub  

**Rosahub** is a full-stack web application designed to provide plant care tips and resources, serving as a virtual nursery. It includes a responsive website for users to explore planting information and an admin dashboard to manage plant data and categories efficiently.  

## Features  

### User-Facing Features  
- Explore detailed plant care tips categorized by plant types.  
- Responsive and user-friendly design for seamless navigation across devices.  
- Contact form for users to submit inquiries or feedback.  

### Admin Dashboard  
- Add, update, or delete plant data and categories.  
- Manage user interactions, including contact form submissions.  
- Secure admin authentication for restricted access.  

### APIs  
- User registration and login functionality.  
- Admin login for managing the dashboard.  
- CRUD operations for plants and categories.  
- Contact form submission handling.  

## Technologies Used  

- **Frontend and Backend:** Next.js  
- **Styling:** Tailwind CSS, Mantine UI  
- **Database:** MongoDB  
- **State Management:** React Query  
- **Language:** TypeScript  

## Future Enhancements  

- Add advanced search functionality for plants.  
- Implement user profiles and saved plant care lists.  
- Introduce analytics for admin to track user interactions.
